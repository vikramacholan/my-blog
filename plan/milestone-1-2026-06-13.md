# Milestone 1 Implementation Plan

## Goal Description
Implement the features requested in `milestone-1.md`:
1. Fix the mobile layout for both the blog post list page and individual blog posts (ensure proper responsiveness, so the sidebar doesn't squish the main content).
2. Update the browser title from "Create Next App" to a relevant blog title.
3. Add the "Catppuccin Mocha" theme as the default, include a dropdown to switch between "Light" and "Catppuccin Mocha", and apply the mocha color palette.
4. Organize the implementation plans by moving the old plan to a `plan` directory and saving this plan there as well.

## User Review Required

> **Dependency Addition:** I will install `next-themes` to handle the theme switching smoothly without hydration mismatches. Please approve this addition.

### 3. Layout & Title (Next.js & Responsive Fixes)
#### [MODIFY] `src/app/layout.tsx`
- **Metadata Title:** Change `title: "Create Next App"` to `title: "My Blog"`.
- **Theme Provider:** Wrap the body content inside `<ThemeProvider attribute="class" defaultTheme="mocha" themes={['light', 'mocha']}>` (extracted to a Client Component `ThemeProvider` if needed for App Router, or just import it).
- **Mobile Responsiveness:** Change the `body` and `div` layout wrappers to allow scrolling on mobile, while retaining fixed scrollable panes on desktop:
  - From: `min-h-full h-screen overflow-hidden flex flex-col`
  - To: `min-h-screen lg:h-screen lg:overflow-hidden flex flex-col`
  - Container from: `flex-1 flex overflow-hidden`
  - To: `flex-1 flex flex-col lg:flex-row lg:overflow-hidden`
  - Make `main` scrollable on desktop: `flex-1 lg:overflow-y-auto`

### 4. Theme & Sidebar
#### [MODIFY] `src/app/globals.css`
- Add the `.mocha` class definition mapping Tailwind's default colors (like `--color-white`, `--color-gray-50`, `--color-indigo-600`, etc.) to Catppuccin Mocha equivalents (`#1e1e2e`, `#11111b`, `#cba6f7`, etc.). This will instantly theme the app without changing component logic.

#### [NEW] `src/components/ThemeSwitcher.tsx`
- Create a simple Client Component with a dropdown `<select>` that hooks into `next-themes`'s `useTheme()` to allow switching between "light" and "mocha".

#### [MODIFY] `src/components/BlogSidebar.tsx`
